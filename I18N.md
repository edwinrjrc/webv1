# Internacionalización (i18n) — Innova Viajes

## Stack i18n

Este proyecto usa **[@ngx-translate/core](https://github.com/ngx-translate/core)** para la internacionalización en tiempo de ejecución (runtime), lo que permite cambiar de idioma sin recompilar la aplicación.

| Paquete | Versión | Propósito |
|---|---|---|
| `@ngx-translate/core` | 17.x | Motor de traducción |
| `@ngx-translate/http-loader` | 16.x | Carga JSON de traducciones vía HTTP |

---

## Idiomas soportados

| Código | Idioma | Archivo |
|---|---|---|
| `es` | Español | `src/assets/i18n/es.json` |
| `en` | English | `src/assets/i18n/en.json` |

**Idioma por defecto / fallback:** `es` (Español)

---

## Dónde viven los archivos de traducción

```
src/
└── assets/
    └── i18n/
        ├── es.json   ← Español (idioma base)
        └── en.json   ← English
```

Los archivos JSON están organizados en secciones temáticas:

```jsonc
{
  "header": { ... },        // Cabecera / navbar
  "footer": { ... },        // Pie de página
  "search": { ... },        // Formulario de búsqueda de vuelos y hoteles
  "fares": { ... },         // Modal de selección de tarifas
  "reservation": { ... },   // Página de datos de reserva
  "passengerForm": { ... }  // Formulario de datos de pasajero
}
```

---

## Cómo usar las traducciones en templates

```html
<!-- Pipe translate -->
<span>{{ 'header.brand' | translate }}</span>

<!-- En atributos HTML -->
<input [placeholder]="'search.origin' | translate" />
<button [attr.aria-label]="'header.language' | translate">...</button>
```

## Cómo agregar nuevas claves

1. **Agrega la clave** en `es.json`:
   ```json
   {
     "miSeccion": {
       "miClave": "Mi texto en español"
     }
   }
   ```

2. **Agrega la traducción** en `en.json`:
   ```json
   {
     "miSeccion": {
       "miClave": "My text in English"
     }
   }
   ```

3. **Usa la clave** en el template:
   ```html
   {{ 'miSeccion.miClave' | translate }}
   ```

> **Fallback seguro:** Si una clave no existe en el idioma activo, `@ngx-translate` retorna automáticamente el valor del idioma de fallback (`es`). Si tampoco existe ahí, muestra la clave en su lugar.

---

## Cómo agregar un tercer idioma

1. **Crea el archivo** `src/assets/i18n/pt.json` (por ejemplo, para Portugués).

2. **Registra el idioma** en `LanguageService`:
   ```typescript
   // src/app/_services/language.service.ts
   export type SupportedLanguage = 'es' | 'en' | 'pt';
   const SUPPORTED_LANGUAGES: SupportedLanguage[] = ['es', 'en', 'pt'];
   ```

3. **Agrega la opción** al selector en `cabecera.component.html`:
   ```html
   <li>
     <button class="dropdown-item" (click)="switchLanguage('pt')">
       🇧🇷 Português
     </button>
   </li>
   ```

4. ¡Listo! No se requiere recompilar.

## Selector de idioma en la UI

El selector de idioma se encuentra en la **cabecera (navbar)** y es visible en pantallas medianas y grandes (`d-none d-md-flex`). Persiste la preferencia del usuario en `localStorage` con la clave `app_language`.

- **Componente:** `src/app/cabecera/cabecera.component.html`
- **Servicio:** `src/app/_services/language.service.ts`

---

## Cambiar el idioma por código

```typescript
import { LanguageService } from './_services/language.service';

constructor(private langService: LanguageService) {}

// Cambiar idioma
this.langService.use('en');

// Obtener idioma actual
const lang = this.langService.currentLang; // 'es' | 'en'
```
